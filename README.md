# 🐦 Twitter Rumor Detection using Machine Learning & NLP

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB.svg?style=flat&logo=python&logoColor=white)](https://www.python.org/)
[![NLTK](https://img.shields.io/badge/NLTK-NLP_Preprocessing-3776AB.svg?style=flat)](https://www.nltk.org/)
[![Scikit-Learn](https://img.shields.io/badge/Scikit_Learn-Text_Classification-F7931E.svg?style=flat&logo=scikit-learn&logoColor=white)](https://scikit-learn.org/)

A Natural Language Processing (NLP) and Machine Learning classification project designed to identify rumor vs non-rumor tweets across social media datasets (2015–2016 PHEME dataset).

---

## 🌟 Key Highlights

- **NLP Preprocessing Pipeline**: Tokenization, stop-word removal, lemmatization, and TF-IDF feature extraction.
- **Algorithm Benchmarking**: Compares classification performance across **Logistic Regression**, **Random Forest**, and **K-Nearest Neighbors (KNN)** algorithms.
- **Evaluation Metrics**: Assesses models using Precision, Recall, F1-Score, Confusion Matrices, and Accuracy scores.

---

## 🛠️ Tech Stack & Libraries

- **Language**: Python 3.10+
- **Natural Language Processing**: NLTK, Regular Expressions (`re`)
- **Machine Learning**: Scikit-Learn (TF-IDF Vectorizer, Classifiers)
- **Data Handling & Viz**: Pandas, NumPy, Matplotlib, Seaborn

## 🚀 Quickstart & Setup

```bash
# 1. Clone repository

```
